1. AI-Powered Email Automation Workflow

Built an AI-powered email automation workflow using n8n, integrating AI, vector search, and Gmail to automate email understanding and responses.

Workflow:

Gmail Trigger → Text Classifier → AI Agent → Pinecone Vector Store → AI-generated Response → Gmail Reply

Technologies Used:
- n8n – Workflow Automation
- OpenAI – Text Classification and AI Responses
- Pinecone – Vector Database and Knowledge Retrieval
- Gmail – Email Trigger and Automated Replies
- Embeddings – Semantic Search and Retrieval

Key Concepts Learned:
- AI Agents
- Retrieval-Augmented Generation (RAG)
- Vector Databases
- Embeddings and Semantic Search
- LLM Integration
- Workflow Automation

Project Outcome:

This project helped me understand how AI Agents, RAG, vector databases, and workflow automation can be combined to build practical AI solutions.
